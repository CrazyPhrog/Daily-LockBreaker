# Changelog

## v0.1.0

- Play the timing game in a browser using Space or the on-screen button.
- Open successive locks with increasing difficulty or practice with unlimited misses.
- Keep a local best streak, with a session fallback if browser storage is blocked.
- Run automated browser rules tests for progression, timing boundaries, and saved data.
- The repository includes the original C# MonoGame prototype and its separate rule checks.
