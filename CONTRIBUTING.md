# Contributing

Use [GitHub Issues](https://github.com/CrazyPhrog/Daily-LockBreaker/issues) to report bugs. Include the browser or operating system, reproduction steps, and expected and actual behavior.

Follow the [README](README.md) to run the game and its tests. Create a branch for your change, keep commits focused, and open a pull request describing the change and how you verified it. For browser changes, also check the controls with a keyboard and a touch device if available.
